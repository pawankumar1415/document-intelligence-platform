Core Features

Everything you need to assess narrative quality

From a single document review to thousands of rows in an Excel batch — AI Narrative Search handles the full workflow with consistent, auditable scoring.

📄
Single Narrative Scoring
Paste or type any narrative text. Get an instant compliance score, quality breakdown by criterion, and a detailed list of issues with severity ratings.
📊
Batch Processing
Upload an Excel (.xlsx, .xls) or CSV file. Every row is scored independently with results shown in an expandable table. Export the full run as CSV.
🔍
Abnormality Detection
Upload reference narratives to build a "gold standard" corpus. The AI compares each submission against the closest matches and surfaces deviations — missing info, unusual claims, data discrepancies.
✏️
AI-Powered Rewrite
When a narrative scores below threshold, the AI generates an improved version that preserves the original facts while fixing the identified quality issues.
📋
Custom Rubrics
Define your own scoring rubric with weighted criteria. Ship with a 7-criterion default rubric (Clarity, Completeness, Accuracy, Structure, Tone, Jargon, Dates) or create domain-specific ones.
📈
Analytics Dashboard
Track pass/warn/fail rates over time, average compliance score, reference library size, and recent scoring activity — all in a single dashboard.
How It Works

From upload to insight in four steps

No configuration required for single scoring. For reference-based detection, upload your gold-standard file once and it's indexed automatically.

1
Upload or Paste
Paste a single narrative into the text area, or upload an Excel/CSV file for batch processing. Any column layout is accepted — the parser detects the ID and narrative columns automatically.
2
Select Rubric & Model
Choose a scoring rubric (or use the default) and select your preferred LLM provider and model. Adjust reference depth (top-k) to control how many examples are retrieved.
3
AI Scores & Analyses
Layer 1 scores the narrative against each rubric criterion. Layer 2 retrieves the most similar reference narratives from the vector store and identifies abnormalities.
4
Review & Export
View the verdict (PASS / WARN / FAIL), criterion breakdown, detected abnormalities with evidence, and an optional AI-rewritten version. Export batch results as CSV.
Scoring Engine

Two-layer AI analysis

A rubric layer evaluates writing quality. A reference layer detects semantic deviations against your indexed corpus. Together they give a complete picture of narrative health.

L1
Rubric Compliance
Quality scoring 0–10
Evaluates narrative against each rubric criterion
Returns score with per-criterion pass/fail list
Deducts points for HIGH (−2), MEDIUM (−1), LOW (−0.5) severity issues
PASS ≥ 8.0 · PASS_WITH_WARNINGS ≥ 6.0 · FAIL < 6.0
Custom rubrics with unlimited criteria
L2
Reference Abnormality Detection
Semantic comparison via pgvector
Embeds the narrative and retrieves top-k similar references
LLM compares submission against retrieved examples
Flags: missing_information, unusual_claim, data_discrepancy, structural, tone
Each flag includes severity (HIGH/MEDIUM/LOW) and quoted evidence
Skipped gracefully if no reference corpus is indexed
Data Formats

Works with any Excel layout

The parser automatically detects the correct column layout — no manual mapping required. It searches for ID-like columns (id, uid, ref, project) and narrative-like columns (narrative, text, description, content, summary) by keyword matching against headers.

Rows with empty IDs are skipped automatically. All extra columns are preserved and included in the reference embedding for richer similarity matching.

Multi-row project report format is supported — detected automatically by data structure (rows where the first column is empty, the second is a project name, and the fourth contains a RAG status value).
